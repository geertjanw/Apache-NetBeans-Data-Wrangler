A real .xlsx workbook with two sheets: orders (8 rows) and products (6 rows). Opens in a spreadsheet-style Visual tab; the Query tab reads it with DuckDB's read_xlsx (excel extension installed on first use) and comes with commented tips.

Try in the Query tab:
SELECT city, sum(quantity*unit_price) FROM read_xlsx('sample.xlsx') GROUP BY ALL;
SELECT o.product, p.category, o.quantity FROM read_xlsx('sample.xlsx', sheet='orders') o JOIN read_xlsx('sample.xlsx', sheet='products') p USING (product);
PIVOT read_xlsx('sample.xlsx') ON city USING sum(quantity*unit_price) GROUP BY product;
