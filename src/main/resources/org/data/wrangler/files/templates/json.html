A JSON array of 8 orders with nested objects (customer), arrays of objects (items) and string arrays (tags). DuckDB's read_json_auto maps them to STRUCT and LIST columns.

Try with Query with DuckDB:
SELECT customer.city, count(*) FROM read_json_auto('orders.json') GROUP BY ALL;
SELECT order_id, unnest(items, recursive := true) FROM read_json_auto('orders.json');
SELECT order_id, list_sum(list_transform(items, i -> i.qty * i.price)) AS total FROM read_json_auto('orders.json') ORDER BY total DESC;
SELECT unnest(tags) AS tag, count(*) FROM read_json_auto('orders.json') GROUP BY ALL;
