A real Apache Parquet file (zstd, 200 rows) with an orders dataset: order_id, customer, city, product, quantity, unit_price, ordered_at, a VARCHAR[] tags column and a STRUCT meta column. Opens in a Visual tab (schema, storage, preview) with a Query tab.

Try in the Query tab:
SELECT city, count(*), sum(quantity*unit_price) AS revenue FROM read_parquet('sample.parquet') GROUP BY ALL ORDER BY revenue DESC;
SELECT product, list_contains(tags,'display') AS has_display, meta.src FROM read_parquet('sample.parquet') LIMIT 10;
SELECT date_trunc('week', ordered_at) AS wk, sum(quantity*unit_price) FROM read_parquet('sample.parquet') GROUP BY ALL ORDER BY wk;
SELECT path_in_schema, total_compressed_size FROM parquet_metadata('sample.parquet');
