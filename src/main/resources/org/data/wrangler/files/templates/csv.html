Creates a small CSV file with a header row (id, name, city, amount, created_at). Right-click it for Query with DuckDB or Convert with DuckDB.

Try:
SELECT * FROM sniff_csv('data.csv'); — what DuckDB detected
SELECT city, sum(amount) FROM read_csv('data.csv') GROUP BY ALL;
SELECT *, amount * 1.21 AS with_vat FROM 'data.csv' WHERE created_at >= DATE '2026-01-02';
CREATE OR REPLACE TABLE data AS SELECT * FROM 'data.csv';
